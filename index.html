Check my website Quick answers

Needs a Windows, Mac or Linux computer. Runs on your computer; nothing you check is sent to anyone.

Check your website now

Type an address. It takes about a minute.

It only reads the site, the way a search engine does, and reads up to 60 pages. The first check after a quiet spell can take up to a minute to wake up.

Install in 3 steps

About five minutes, the first time. No account needed.

  1. 1

    Get the zip and unzip

    The free copy is a small zip file. Send us a message for it. Then right-click the zip and choose Extract All.

  2. 2

    Install Python once

    Get it free at python.org. On the first screen, tick "Add Python to PATH".

  3. 3

    Double-click to start

    Open the folder and double-click Studio Hub.bat. Your browser opens the checker. The first start sets itself up in about a minute.

Stuck? The zip has a plain START HERE.txt. Mac or Linux: run start.sh.

Then check any website

Type the address, press Check this website, then read the Fix first list. A normal check takes under a minute. It opens as a normal web page, so it is easy to read.

Quick answers

Does it cost anything?

No. It is free to use.

Does it change my website?

No. It only reads, the way a search engine does.

Will it get me to number one on Google?

No tool can promise that, and this one does not. It shows what is technically wrong and how to fix it. That is the part you can control.

Can I use it for my clients' websites?

Yes. Check them, share the reports, and sell your own SEO services. You may not sell the software itself or offer it online to others. The license is inside the download.
